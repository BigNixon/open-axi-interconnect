# Quick Start

Get the Open AXI Interconnect running in under 5 minutes.

## 1. Clone the Repository

```bash
git clone https://github.com/open-axi-interconnect/open-axi-interconnect.git
cd open-axi-interconnect
```

## 2. Install Dependencies

```bash
pip install -r requirements.txt
```

## 3. Run a Simulation

```bash
make sim
```

You should see output indicating the simulation is running and passing.

## 4. View Results

Simulation waveforms and logs are generated in the `sim/` directory.
