# Getting Started

Welcome! This section will help you get up and running with the Open AXI Interconnect in minutes.

## Prerequisites

Before you begin, ensure you have the following tools installed:

| Tool | Version | Purpose |
|------|---------|---------|
| Python | 3.8+ | cocotb testbench runtime |
| Verilator | 5.0+ | RTL simulation |
| cocotb | 1.8+ | Python testbench framework |
| Make | 4.0+ | Build automation |
